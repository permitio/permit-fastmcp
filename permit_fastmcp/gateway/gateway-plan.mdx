# Plan to implement an MCP gateway with FastMCP

The gateway is a server that can be used to proxy requests to the FastMCP server.

The gateway will be used to:

- Proxy requests to the FastMCP server
- Add authentication and authorization to the requests
- Add rate limiting to the requests
- Add caching to the requests
- Add logging to the requests


## core
We will use https://gofastmcp.com/servers/proxy and https://gofastmcp.com/servers/composition as a reference for the gateway implementing the gateway with FastMCP.
Gateway will be dynamic adding remote servers to the proxy on the fly.

We will use the permit middleware to add authentication and authorization to the requests.


## dynamic server loading
A dynamic server entry can be added to the gateway on the fly (via fastmcp mounting)
via:
 - gateway.add_server(server_name, server_config)
 - catch-all route to the gateway which includes the proxied server details in the request (either as query params or as a header)
